# 此间·瓷间

本文件夹是从「此间瓷间-最终版.html」独立整理的静态网站发布包。

## 文件结构

- `index.html`：网站首页，内容来自最终版 HTML。
- `ming_ceramics_assets/`：本地字体、图表脚本、背景及贴图。
- `示例图片/工艺/`：工艺贴图。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

## 发布到 GitHub Pages

1. 创建一个 GitHub 仓库。
2. 把本文件夹里面的全部内容上传到仓库根目录；确保 `index.html` 位于仓库根目录，而不是多套一层文件夹。保留 `.nojekyll`。
3. 在仓库 Settings → Pages 中，选择从分支发布（Deploy from a branch）。
4. 选择存放文件的分支（通常为 main），目录选择 `/ (root)`，保存。
5. 等待部署完成，使用 Pages 页面显示的网址访问。

网站无需 npm 安装或构建。不需要上传原项目的备份、开发脚本、表格、虚拟环境或第三方库源码目录。

## 本地预览

完整保留目录结构，用 Edge 或 Chrome 打开 `index.html`。也可以使用任意静态网站服务器预览。

## 联网与素材说明

网站使用 HTTPS 在线文物照片及博物馆详情链接，这些内容仍需联网，且受来源网站可用性影响。本包不包含所有远程高清照片的离线副本。
本地字体、脚本、贴图已经包含。网页仍有较多内嵌图片数据，首次加载速度会受网络影响。
发布包没有替素材授予新的使用许可；素材与第三方库原有权利归属保持不变。

原项目最终版 HTML 未修改。本次仅准备发布文件夹，没有创建仓库或上传发布。
